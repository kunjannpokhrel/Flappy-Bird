## About The Project

Flappy Bird is a small game development project built with Python and Pygame by me alone ofc. The goal is to control a bird, avoid the pipes, and earn points for as long as possible.

The game includes a main menu, a ready screen, gameplay, a game-over screen, and separate screens for choosing a character and a background. It also uses sound effects for actions such as flapping, scoring, collisions, and menu clicks. basically it is fun so check it out

I made this project to practise game development with Pygame and learn how to organize a game using classes and game states and this is actually my second game. i wanted to get familiar with variables, code optimization so i made this project.

## Getting Started

Follow these steps to run the game on your computer.

### Prerequisites

Make sure Python is installed. You can check your installation with:

```sh
python --version
```

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/kunjannpokhrel/Flappy-Bird.git
   ```

2. Enter the project directory:

   ```sh
   cd Flappy-Bird
   ```

3. Install Pygame:

   ```sh
   python -m pip install pygame
   ```

4. Run the game:

   ```sh
   python main.py
   ```

> **Note:** Keep the `classes.py` file and the `assets` folder in the project directory. The game loads images and sound files using relative paths, so the expected asset folders and filenames must be present.

## Controls

| Key | Action |
| ---------------------- | ----------------------------------------------- |
| **Space / Up Arrow** | Flap the bird / start from the ready screen |
| **F11 / F** | Toggle fullscreen |
| **Esc** | Exit the game |
| **Mouse Click** | Navigate menus and select characters or backgrounds |

## Gameplay

Start from the main menu and choose **Play** to enter the ready screen. Press Space or the Up Arrow to begin. Keep the bird airborne, pass through the pipes, and try to get the highest score you can.

If the bird hits a pipe or reaches the screen boundary, the game ends. Return to the main menu to play again or explore the other menu screens.
